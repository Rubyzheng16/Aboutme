# 郑好的个人简历存档 (Zheng Hao's Archive Portfolio)

这是一个基于 **Archive/Folder (档案/文件夹)** 概念设计的个人作品集网站。采用了极简线条感和专业档案室的视觉风格，旨在展示面试官如查阅档案般的沉浸式体验。

## 🌟 核心特性

- **交互式文件夹堆叠 (Interactive Folder Stack)**: 仿真的文件夹堆叠效果，鼠标悬浮时活页提起，点击后丝滑展开查阅。
- **档案式内容呈现 (Document View)**: 所有内容（个人信息、教育、经历、项目、技能）均以“文件档案”的形式排版。
- **极简专业设计 (Minimalist Professional Design)**: 遵循 **Untitled UI** 及 **Square UI** 规范，采用黑白灰金砂色调，强调线条感与几何美学。
- **响应式布局 (Responsive)**: 完美适配桌面与移动端设备。
- **高性能动画 (High Performance)**: 基于 `motion/react` 开发，确保极流畅的过渡效果。

## 🛠️ 技术栈

- **框架**: React 19 + Vite 6
- **样式**: Tailwind CSS 4 (Next-gen engine)
- **动画**: Motion (Framer Motion)
- **图标**: Lucide React
- **字体**: Inter, JetBrains Mono

## 📁 文件夹结构

- `01_PROFILE`: 个人基础信息与优势
- `02_EDUCATION`: 教育背景（广东东软学院）
- `03_EXPERIENCE`: 实习工作经历（鹰驾科技、中科院等）
- `04_PROJECTS`: 项目作品集（企业官网、小程序、Unity实验）
- `05_SKILLS`: 技术栈存档

## 🚀 快速开始

1. 安装依赖: `npm install`
2. 启动开发服务器: `npm run dev`
3. 预览地址: 默认运行在 [http://localhost:3000](http://localhost:3000)
